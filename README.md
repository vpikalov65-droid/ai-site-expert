# AI Site Expert — UX-рецензент сайта

Минимальный Python-агент для дипломной работы по вайбкодингу. Загружает
HTML через requests, извлекает текст с BeautifulSoup и запрашивает у OpenAI
отчёт на русском: 3 достоинства, 3 недостатка и ровно 5 конкретных рекомендаций.

## Установка

Нужен Python 3.12. Выполните из корня проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Если `.venv` уже существует и зависимости установлены, достаточно активации.
В requirements.txt закреплены версии из проверенного локального окружения.

Создайте `.env` в корне проекта, если его ещё нет. Существующий файл
не перезаписывайте. Настройки:

```dotenv
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-4o
```

`OPENAI_MODEL` необязателен; по умолчанию используется `gpt-4o`. Нужны
действующий ключ и доступ к выбранной модели с поддержкой JSON mode.
Ключ загружается из корневого `.env` при обращении к модели. Уже заданные
переменные окружения имеют приоритет. `.env` исключён из Git; не публикуйте его.

## Локальный веб-интерфейс

После установки зависимостей запустите из корня проекта:

```bash
.venv/bin/python -m uvicorn backend.web:app --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000** в браузере. Введите полный URL страницы
и нажмите «Анализировать». Интерфейс покажет индикатор ожидания, затем
три карточки: 3 сильные стороны, 3 слабые стороны и 5 рекомендаций.
При ошибке появится сообщение; можно исправить адрес и повторить запуск.
Для остановки сервера нажмите `Ctrl+C` в терминале.

Запуск сервера и открытие страницы не вызывают OpenAI. Нажатие кнопки
запускает существующую функцию `backend.agent.run(url)` и обращение к платному
API с настройками из вашего `.env`. Вводите адрес подходящей публичной страницы.
Не повторяйте запрос до завершения: после закрытия вкладки сервер может
продолжать уже начатый анализ.

Интерфейс работает локально, без React, Node.js, внешних шрифтов и UI-библиотек.
Сервер слушает только `127.0.0.1`; ключ остаётся на сервере, `.env` не раздаётся.
Индикатор показывает ожидание, а не процент выполнения: агент не передаёт
промежуточный прогресс. CSS адаптирует карточки и форму к узким экранам.

## Запуск CLI

После активации окружения, из корня проекта:

```bash
python backend/agent.py https://example.com
```

Команда обращается к сайту и платному OpenAI API. Запускайте её, когда готовы
использовать API. Для сохранения результата в новый файл:

```bash
python backend/agent.py https://example.com > ux_report.json
```

JSON выводится в stdout; этапы работы и безопасные сообщения об ошибках —
в stderr. Код завершения: 0 при успехе, 1 при ошибке анализа, 2 при ошибке
аргументов CLI. Исходные ответы API и секреты в сообщения об ошибках не включаются.

Использование из Python:

```python
from backend.agent import run

report = run("https://example.com")
print(report["recommendations"])
```

Пример структуры результата (иллюстрация, не реальный анализ example.com):

```json
{
  "strengths": ["Понятный заголовок", "Есть контакты", "Услуга описана"],
  "weaknesses": ["Нет цены", "Не указаны сроки", "Нет примеров работ"],
  "recommendations": [
    "Добавьте стоимость услуги рядом с её описанием",
    "Укажите срок выполнения под заголовком услуги",
    "Разместите три примера выполненных работ",
    "Добавьте кнопку заявки после описания услуги",
    "Опишите этапы работы перед формой заявки"
  ]
}
```

## Ошибки и ограничения

Сетевые сбои и временные HTTP-ошибки повторяются максимум 3 раза **всего**
для каждой операции: первая попытка и два повтора с задержками 1 и 2 секунды.
Для сайта повторяются таймауты, ошибки соединения, HTTP 408, 429 и 5xx;
для OpenAI — ошибки соединения/таймауты, HTTP 408, 409, 429 и 5xx.
Постоянные ошибки (например, 401, 404, исчерпание квоты API) не повторяются.
Встроенные повторы OpenAI SDK отключены. Таймаут сайта — 15 секунд,
API — 30 секунд на попытку. После исчерпания попыток CLI завершится с ошибкой;
`run(url)` передаёт исключение вызывающему коду.

Проверяются тип JSON-объекта, списки непустых строк и точное число пунктов.
Пустой, незавершённый или некорректный ответ модели отклоняется без повторного
платного запроса. Конкретность рекомендаций задаётся инструкцией модели;
смысловую точность нужно оценивать при демонстрации.

Анализируется одна HTML-страница, до 15 000 символов извлечённого текста.
Удаляются script, style, nav и footer. JavaScript не исполняется, переходов
по ссылкам нет. Агент не видит скриншоты и не оценивает визуальный дизайн;
сайты с JS-контентом или защитой от автоматической загрузки могут быть недоступны.
Текст страницы передаётся OpenAI — выбирайте подходящие публичные страницы.

## Тесты без сети и расходов

```bash
python -m unittest discover -s tests -v
python -m compileall -q backend tests
python backend/agent.py --help
```

Тесты используют unittest и unittest.mock из стандартной библиотеки;
реальные запросы к сайтам и OpenAI не выполняются, ключ не требуется.
Проверяются извлечение текста, ограничения, URL, HTTP/сетевые ошибки,
число повторов и задержки, API, JSON, валидация отчёта и CLI.
Веб-тесты используют FastAPI TestClient (HTTPX) и подменяют `agent.run`:
проверяют HTML/CSS/JS, успешный отчёт, неверные запросы, безопасные сообщения
об ошибках, восстановление после ошибки и недоступность приватных файлов.

## Структура

- `backend/agent.py` — функция `run(url)`, проверка отчёта и CLI.
- `backend/site_parser.py` — загрузка HTML и извлечение текста.
- `backend/openai_module.py` — все обращения к OpenAI, настройки и повторы.
- `backend/web.py` — локальный FastAPI-сервер и маршрут `/api/analyze`.
- `frontend/` — HTML, CSS и JavaScript веб-интерфейса.
- `tests/test_agent.py` — автоматические тесты с моками.
- `tests/test_web.py` — HTTP-тесты интерфейса без внешних запросов.
- `docs/first_ux_report.txt` — сохранённый ранее результат проекта.

Для сдачи: запустите тесты, затем самостоятельно выполните один разрешённый
запрос к API и сохраните отчёт для демонстрации. Реальный вызов API при
подготовке этих изменений не выполнялся.
